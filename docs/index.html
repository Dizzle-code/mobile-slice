Was die App kann

Modell öffnen

STL und 3MF, zum Beispiel direkt von MakerWorld.

Slicen auf dem Gerät

Die OrcaSlicer-Engine läuft lokal. Kein Konto, keine Cloud.

Ab auf den P1S

Druck im lokalen Netzwerk senden und den Fortschritt verfolgen.

Installation

Windows

Setup starten. Weil der Installer nicht signiert ist, warnt SmartScreen beim ersten Mal: „Weitere Informationen“ → „Trotzdem ausführen“.

macOS

DMG öffnen und „Mobile Slice“ auf „Programme“ ziehen. Die App ist nur ad hoc signiert: beim ersten Start per Rechtsklick → „Öffnen“ starten oder im Terminal ausführen:

xattr -dr com.apple.quarantine "/Applications/Mobile Slice.app"

Den Zugriff aufs lokale Netzwerk erlauben, sonst wird der Drucker nicht gefunden.

Android

APK auf dem Gerät öffnen und die Installation aus dieser Quelle erlauben.
